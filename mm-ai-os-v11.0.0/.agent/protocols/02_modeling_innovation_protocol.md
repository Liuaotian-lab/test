# 02 Modeling Innovation Protocol

Goal: force explicit model search instead of single-method tunnel vision.

For every question, produce at least three candidates:

1. baseline model;
2. competition-strength model;
3. independent verifier / alternative formulation.

Each candidate must state variables, objective, constraints, data inputs, applicable conditions, failure modes, complexity, validation method, and allowable claim level.

Required artifacts:

- `contracts/questions/<QID>/model_candidates.json`
- `workspace/modeling/<QID>_modeling_options.md`
- `reports/<QID>_model_selection.md`
