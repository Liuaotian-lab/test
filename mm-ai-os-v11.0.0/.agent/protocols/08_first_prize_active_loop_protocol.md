# First-Prize Active Loop Protocol

This protocol upgrades the OS from defensive delivery control to active first-prize search.

## Mandatory loop

1. Build contest strategy and scoring hypothesis.
2. Run problem intelligence and identify hidden requirements/traps.
3. Generate at least four model levels per required question: L0 baseline, L1 contest baseline, L2 advanced, L3 innovative/hybrid.
4. Implement multiple solver variants or produce benchmark artifacts for at least baseline and advanced variants.
5. Produce independent verifier plugins and compare results.
6. Build paper outline, argument map, figure plan and reproducible figure manifest.
7. Run judge simulation and improvement loop.
8. Run final gate and first-prize gate.

## Non-negotiable artifacts

- `workspace/contest_strategy/contest_strategy_plan.json`
- `workspace/problem_intelligence/scoring_points.json`
- `workspace/modeling/<QID>/selected_model.json`
- `results/<QID>/solver_runs/*/result.json`
- `results/<QID>/independent_verification/verifier_compare.json`
- `paper/paper_outline.json`
- `paper/figures_manifest.json`
- `reviews/judge_simulation/aggregate_review.json`
- `quality/first_prize_gate_report.json`

## Claim discipline

Do not claim first-prize readiness if the first-prize gate applies a cap below A.
Do not claim global/certified optimal unless an independent proof or exhaustive verifier exists.
