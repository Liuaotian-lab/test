# Paper Excellence Checklist v6.1

## Front-stage CUMCM style
- [ ] No table-of-contents page.
- [ ] Abstract covers every required question with model, algorithm, result, and concise validation.
- [ ] No explicit `semantic audit` chapter in the final paper.
- [ ] Validation is embedded in each question's result analysis or summarized briefly in model evaluation.
- [ ] Tables use three-line style and no vertical rules.
- [ ] Figures support arguments and are cited in the text.

## Evidence and quality
- [ ] `paper-readiness-gate` allows paper generation.
- [ ] Each key numeric claim maps to result JSON/Excel/log/figure source evidence.
- [ ] Each optimization claim has a trace, comparison, sensitivity, or convergence explanation.
- [ ] Each required output file is referenced consistently.
- [ ] The final PDF is text-searchable/checkable.

## Appendix
- [ ] Appendix A contains complete executable code for all core solvers.
- [ ] Figure-generation scripts are included when figures support important claims.
- [ ] Appendix code hashes correspond to the code used for final outputs.
