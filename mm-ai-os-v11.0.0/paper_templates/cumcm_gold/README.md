# CUMCM Gold LaTeX Template - v6.2 policy

This template implements `docs/CUMCM_PAPER_STANDARD_V0_1.md`.

Final paper structure:

1. 题目
2. 摘要 / 关键词
3. 一、问题重述
4. 二、问题分析
5. 三、模型假设
6. 四、符号说明
7. 五、模型的建立与求解, with each question containing 建模思路/模型建立/求解算法/求解结果与解释
8. 六、模型的分析与检验, concise but independent
9. 七、模型的评价与推广
10. 参考文献
11. 附录 A 完整程序代码; 附录 B 补充结果或数据表

Hard rules:

- No table of contents.
- No explicit front-stage section named 数据处理与语义审计 or other OS-internal audit terms.
- PDF must be searchable text, not full-page images.
- Complete executable code, not pseudocode fragments, is required in appendix A.
- Figures and tables must be cited and support an explicit conclusion.
- Abstract should be information-dense and bold core models, algorithms, and numeric results.
