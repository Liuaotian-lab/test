# Module: CLI

## Purpose

Command-line entrypoint and command registry for MM-AI OS.

## Inputs

- CLI arguments from `scripts/mmtool.py`, `python -m mmos.cli`, or installed `mmos` console script.

## Outputs

- JSON payloads printed through `print_json`.
- Files generated by delegated workflow/domain modules.

## Public API

- `mmos.cli.main(argv=None)`
- `mmos.cli.build_parser()`

## Structure

- `main.py`: runtime entrypoint.
- `parser.py`: argparse command registration.
- `dispatch.py`: exit-code mapping.
- `commands_*.py`: grouped command handlers.
- `commands_common.py`: shared imports and JSON output helper.

## Do Not

- Do not put heavy business logic in `parser.py`.
- Do not remove command names without a migration note.
- Do not break `scripts/mmtool.py` compatibility.
