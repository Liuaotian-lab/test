# Module: Paper LaTeX

## Purpose

Build and compile LaTeX paper artifacts for CUMCM-style submissions.

## Inputs

- Case results and reports.
- Paper templates.
- Evidence and citation artifacts.

## Outputs

- LaTeX source files.
- Optional compiled PDF files.
- Paper environment diagnostics.

## Public CLI

- `latex-paper-build`
- `latex-paper-compile`
- `paper-env-doctor`

## Do Not

- Do not treat generated paper text as final correctness evidence.
- Do not bypass final gate and package gate.
